# T01 MATLAB 现场演示

在 MATLAB R2026a 中打开同目录的 `T01_demo.m`，点击“运行”即可。也可以将当前文件夹切换到此目录，输入：

```matlab
T01_demo
```

程序会重新计算一个短算例，使用 MATLAB 独立积分径向 ODE，并生成一张包含边界、半径、误差及压力场的四联图。MATLAB 负责控制、参考积分、检查、绘图和保存；二维自由边界数值求解仍是已核验的 C++ 程序，通过本机 WSL Ubuntu-24.04 调用。不需要 Windows Python 科学计算包或额外 MATLAB 工具箱。

固定输入：64×64 网格、32控制点、时间步长0.04、终止时间0.2，lambda=0.5，c_B=10，G0=0.2，R0=0.5。

可选会前操作：

```matlab
T01_demo('prepare') % 会前预编译；不进行数值实验
```

重开最近一次结果：

```matlab
T01_demo('replay')  % 明确标注“已有结果回放”，不会假装新计算
```

每次计算在 `runs` 下新建时间戳目录，保存 `.mat`、可重新编辑的 `.fig`、PNG、PDF、误差CSV、摘要JSON，以及这一轮原始数据和求解器日志。也可以直接打开其中的 `.fig` 文件查看。

`backend` 包含原A组固定T01的源码副本、标准库Python构建驱动和单项配置，不依赖原项目目录。请整体保留此文件夹。编译在现有WSL中进行，需要原先已安装的C++工具链、CMake和GSL等环境；初次运行会编译，以后自动复用缓存。

独立参考半径满足：

\[
R'(t)=\frac{G_0c_B I_1(\sqrt{\lambda}R)}{\sqrt{\lambda}I_0(\sqrt{\lambda}R)},\qquad R(0)=R_0.
\]

本演示查验输入、求解、新输出、独立参考及误差的完整流程。短算例的误差不是完整加密试验结论，也不预填专家通过意见。
