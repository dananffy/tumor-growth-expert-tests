# 用MATLAB完成一次T01短算例

本页用于专家获取程序并查验一次新的数值计算。已配置环境下，操作入口为 `A/matlab_demo/T01_demo.m`。完整数学解释及加密结果由项目组会前报告提供。

## 1. 获取完整代码

在仓库主页选择 **Code → Download ZIP** 并解压，保留整个目录。已有本地克隆的读者可先同步采用的代码版本。不要只复制一个 `.m` 文件：`matlab_demo/backend` 包含数值求解所需源码。

## 2. 阅读运行说明

先看 [MATLAB演示README](../A/matlab_demo/README.md)。本入口在 Windows MATLAB R2026a 实测，使用已配置的 WSL Ubuntu-24.04、C++工具链、CMake和GSL。MATLAB完成控制、独立ode45参考、检查和绘图；二维求解沿用原T01 C++程序。不需要Windows端Python科学计算包。

## 3. 运行一个新算例

在MATLAB中将当前文件夹切换到解压后的仓库根目录，再执行：

```matlab
cd('A/matlab_demo')
T01_demo
```

也可以直接打开 `T01_demo.m` 并点击运行。会前可先执行 `T01_demo('prepare')` 预编译。

固定配置为64×64网格、32控制点、dt=0.04、T=0.2，lambda=0.5、c_B=10、G0=0.2、R0=0.5。首次启动、编译和绘图均需要时间，耗时按实际设备记录，完整数值测试另按各项说明运行。

## 4. 查验新输出

每次新建 `A/matlab_demo/runs/<时间戳>_run/`，包含：

- `T01_matlab_demo.png` / `.fig`：边界、半径、相对误差和压力场四联图。
- `radius_comparison_matlab.csv`：相同保存时刻的数值半径、独立参考与误差。
- `summary.json` / `T01_result.mat`：输入、运行ID、参考积分与数值检查记录。
- `raw/`：本次实际求解的边界和场数据、构建/运行日志及源码快照。

核对这是本次新运行的时间戳和run ID，然后查看数值半径是否跟随独立参考、误差如何变化，并定位相应原始数据。

11月25日会前实测终点相对误差为0.2788%，是一个短算例的记录，不是统一通过阈值，也不能替代完整的精度/收敛试验或专家意见。

如需查看已有结果，执行 `T01_demo('replay')`；界面明确标为已有结果回放，不进行新计算。
