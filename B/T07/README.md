本目录保留合作者11月24日提供的MATLAB代码，位于`reference/`。本轮不改变反演模型或默认采样参数，暂不将它列为与数学报告一致、已经核验完成的反演算例。

## 文件

- `reference/MCMC_Test1b.m`、`MetroHast5.m`、`Test.m`、`solver_2D.m`：常数增长率脚本及求解器。
- `reference/MCMC_Test3.m`、`MetroHast_RandomField.m`、`G_Function.m`、`G_Fun.m`、`Random_Field.m`：空间增长场脚本。

MATLAB运行采样器需要Statistics and Machine Learning Toolbox的`normrnd`。这些脚本可能触发长时间MCMC，未作为快速运行命令提供。

## 采用前需要核对

常数脚本的真值为1，但采样器只接受[0.5,0.8]，声明的高斯先验未进入接受率。观测生成没有实际加噪；保留200至800共601个状态，与拟采用的600个状态不同。其输出MSE也是样本误差统计，不能直接称为多次后验均值估计的MSE。

场脚本现用含噪观测、先验标准差0.4/0.3/0.2、噪声标准差0.125、500个状态；默认域及真值仍需与所选报告实验核对。原说明中部分字段已过时，未作为本目录运行说明沿用。
